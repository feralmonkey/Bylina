Tagging
=======
1. Create an empty struct in TagComponents.h
	e.g
		struct PlayerTag {};
2. Add emplacement logic in MapLoader.cpp
			// Player Tag
			sol::optional<sol::table> player_tag = entity["components"]["player_tag"];
			if (player_tag) {
				registry.emplace<PlayerTag>(newEntity);
			}
